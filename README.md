# المكتبة القرآنية 📖

موقع عربي أنيق متخصص في قراءة سور القرآن الكريم برواية ورش عن نافع، مع أذكار وتلاوات صوتية عالية الجودة.

## 🌟 المميزات

✅ **قراءة القرآن**
- جميع سور القرآن (114 سورة)
- رواية الإمام ورش عن نافع المدني
- بحث سريع عن السور
- عرض احترافي للآيات

✅ **الاستماع الصوتي**
- تلاوات صوتية برواية ورش
- عدة قراء موثوقين
- مشغل صوتي متقدم
- تحكم كامل بالصوت والتشغيل

✅ **الأذكار**
- أذكار الصباح والمساء
- أذكار بعد الصلاة
- أذكار عند النوم
- أذكار متنوعة أخرى

✅ **التصميم**
- واجهة عصرية وأنيقة
- متوافق مع جميع الأجهزة (Responsive)
- يعمل على الهواتف والحواسيب
- ألوان هادئة وممتعة للعين

## 📱 الاستخدام

### عرض القرآن
1. اختر سورة من القائمة
2. أو ابحث عن اسم السورة برقمها
3. اقرأ النص مباشرة

### الاستماع الصوتي
1. اختر القارئ من القائمة
2. اختر السورة المطلوبة
3. اضغط "تشغيل التلاوة"
4. استمتع بالتلاوة مع التحكم الكامل

### عرض الأذكار
1. اختر من القوائم الجانبية
2. لتصفية حسب الفئة (صباح، مساء، إلخ)
